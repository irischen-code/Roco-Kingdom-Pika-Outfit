# 皮卡随机商店 · 规划助手

> 洛克王国随机商店时装规划工具 —— 输入你有什么、想要什么，输出多久能凑齐、怎么规划最优。

🔗 **在线使用：[irischen-code.github.io/Roco-Kingdom-Pika-Outfit](https://irischen-code.github.io/Roco-Kingdom-Pika-Outfit/)**

---

## 功能介绍

### 规划助手
- **命中概率计算**：基于当前卡池大小，精确计算今日翻到目标部件的概率
- **集齐周期预测**：蒙特卡洛模拟（3000次）给出欧皇 / 正常 / 非酋三档集齐天数与具体日期
- **许愿星收支规划**：计算目标总花费，判断现有星数是否够用、还需攒几天
- **清池策略建议**：识别卡池中低价非目标部件，推荐提前买断以压缩卡池、提升命中率
- **待入池套装估算**：目标套装尚未入池时，按入池日期做未来卡池快照，提前估算入池后概率

### 卡池总览
- **入池倒计时面板**：全页面常驻悬浮面板，实时显示下一批套装的精确入池倒计时
- **卡池总览**：全部专题套装一览，区分已入池 / 待入池 / 挂起状态

### 我的衣橱（新）
- **衣橱记录**：勾选已集齐的套装，生成专属衣橱长图，可保存分享
- **异色套装支持**：单独标记已解锁的异色版本，在衣橱图中独立展示
- **未集齐套装置灰**：所有套装均展示，未拥有的以置灰样式呈现，一目了然
- **衣橱页账号切换**：点击「当前账号 ▾」可直接切换账号，生成对应账号的衣橱图

### 多账号管理（新）
- **多账号支持**：可创建多个账号（如洛克1、洛克2），各账号数据完全隔离
- **快速切换**：账号 chip 行一键切换，切换后全站数据实时更新
- **账号管理**：支持重命名、删除账号，管理弹窗展示各账号已收集套装数

### 其他
- **PWA 支持**：可添加到手机主屏幕，像 App 一样使用，支持离线缓存
- **意见反馈**：内置 QQ 群入口，方便反馈问题和数据更新诉求

## 数据说明

- 内置数据为时点快照，当前收录 **44 套**时装（含待入池，截至乐团协奏曲专题）
- 卡池状态根据系统实时日期自动过滤，未入池套装不参与概率计算
- 每两周随游戏更新迭代一次数据

## 技术栈

单文件纯原生实现，无任何框架依赖。

- HTML / CSS / JavaScript（Vanilla）
- 蒙特卡洛概率引擎（3000次模拟）
- html2canvas（衣橱长图生成）
- PWA：manifest.json + Service Worker（离线缓存）
- 完整适配 PC 端与移动端 H5
